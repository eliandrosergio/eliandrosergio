## 🚀 Projectos & Empresa

### 🏢 NGOLABYTE TECHNOLOGIES SERVICES
A software house que co-fundei, focada em soluções tecnológicas para o mercado angolano.

### 💱 TaxaAO
API REST que agrega as taxas de câmbio dos principais bancos angolanos e do BNA, com histórico diário e a melhor taxa para cada par de moedas, num só lugar. Feita com NestJS, Prisma e PostgreSQL. Projecto concluído (mas aberto a melhorias) — o repositório é privado, mas o site está no ar.
🔗 [taxa.ao](https://taxa.ao)
