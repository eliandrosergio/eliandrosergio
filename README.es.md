## 🚀 Proyectos y empresa

### 🏢 NGOLABYTE TECHNOLOGIES SERVICES
Una empresa de software que cofundé, centrada en soluciones tecnológicas para el mercado angoleño.
🔗 [ngolabyte.ao](https://ngolabyte.ao)

### 💱 TaxaAO
API REST que agrega los tipos de cambio de los principales bancos angoleños y del BNA (Banco Nacional de Angola), con histórico diario y el mejor tipo para cada par de divisas, todo en un solo lugar. Hecha con NestJS, Prisma y PostgreSQL. Proyecto terminado (pero abierto a mejoras): el repositorio es privado, pero el sitio está en línea.
🔗 [taxa.ao](https://taxa.ao)
